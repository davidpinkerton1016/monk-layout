The tool stores the base actions that FFXIV upgrades through traits. For example, Bootshine displays as Leaping Opo at level 100. Masterful Blitz changes to the available Blitz through the game's own action replacement. It does not need separate buttons for Phantom Rush or the other Blitz results.

The four empty Ctrl slots do not receive new keyboard bindings. Ctrl+Z, Ctrl+X, Ctrl+C and Ctrl+V remain available for their existing functions.

This is a recommended starting layout. Keep skills you use often on comfortable keys, and use the preview to decide whether to retain your existing bindings.
